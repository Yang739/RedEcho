# pages/ 主包页面（4 个 tab）

| 页面 | 路径 | 职责 |
|---|---|---|
| 首页 | `pages/home/` | 卡片推荐流、积分概览、演出现场入口；骨架屏 + 下拉刷新 + 上拉加载 |
| 演出 | `pages/show/` | 演出列表（分段筛选 + 演出中徽标） |
| 创作 | `pages/create/` | 场景网格 + 作品画廊入口 |
| 我的 | `pages/mine/` | 用户资料 / 积分 / 菜单（积分明细、订单、设置） |

tabBar 配置见 `app.json`。主包仅放 tab 页，重交互页放分包（见 `packages/`）。
