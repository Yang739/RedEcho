## 三、提交流程（参考）

1. 在中国版权保护中心官网注册账号 → 在线填报《登记申请表》→ 提交并打印（带 barcode）。
2. 按本清单准备好说明书（含截图）、源程序清单、身份证明。
3. 线上上传 PDF 或邮寄纸质材料；缴纳登记费。
4. 受理 → 审查（一般 30–60 个工作日，加急另计）→ 下发《计算机软件著作权登记证书》。
