## 一、软件概述

红韵智演（以下简称"本软件"）是一款应用于**红色旧址的思政教育微信小程序**。软件通过「真人演员表演 + 游客实时投票决策 + AIGC 生成内容」的组合方式，让游客从被动旁观者转变为演出参与者，在沉浸式互动演出中感悟红色历史，并可将个性化纪念（AIGC 明信片）保存、分享或现场打印带走。

软件分为**游客端**与**工作人员端（场务 / 演员）**两套视图，涵盖资料阅读、实时互动演出、AIGC 明信片创作、个人积分成长、周边兑换与硬件打印等能力。

---

## 二、开发背景与目的

- **背景**：红色旧址参观多以展板、讲解为主，游客参与感弱、记忆留存浅。将"沉浸式互动演出 + 思政教育"结合，是红色文化传播的新型载体。
- **目的**：
  1. 以"游客实时投票决定剧情走向"提升参与感与沉浸感；
  2. 以 AIGC 明信片把红色记忆转化为可带走的个性化纪念；
  3. 以积分成长体系激励持续学习与互动；
  4. 为工作人员（场务 / 演员）提供演出控制与 AI 辅助工具，降低现场执行门槛。

## 四、软件总体架构

本软件采用 **「小程序原生前端 + 云开发 BFF（Backend For Frontend）」** 轻后端架构：前端负责渲染与交互，所有业务规则、数据聚合、第三方调用（IM / AIGC / 支付 / 短信）收敛到**云函数层**，避免端上暴露密钥、降低端上逻辑复杂度。

### 4.1 技术栈分层

| 层 | 职责 | 关键产物 |
|---|---|---|
| 表现层 | 页面与组件渲染、交互反馈 | `pages/`、`packages/`、`components/` |
| 逻辑层 | 页面业务逻辑、表单校验、本地状态 | 各页面 `.js` |
| 服务层 | 统一调用云函数、错误归一化、重试、缓存 | `services/*.js` |
| 全局层 | 登录态、用户信息、主题、字号偏好 | `app.globalData` + `store/` |
| 云函数 BFF 层 | 鉴权、参数校验、DB/IM/AIGC 编排、限流 | `cloudfunctions/*` |
| 基础能力层 | 云数据库 / 云存储 / IM / AIGC / 支付 | 云开发控制台资源 |

**数据流原则**：端上不直接连数据库；所有读写经云函数。实时类走 IM 推送，非实时类走云函数 request-response。

## 五、主要功能与模块说明

### 5.1 游客端功能

#### 5.1.1 首页与资料阅读（核心模块）
- 首页以「湖南主题红色史料」为内容源（`services/resources.js`，约 22 条、6 大分类：历史事件 / 湘籍伟人 / 红色旧址 / 湖湘精神 / 英烈丰碑），前端直接读取，无需灌云数据库。
- 首页从全库**随机推荐 3 张**卡片，点「更多 ›」进入资料中心；优先推送**未读**资料，全部读完则继续随机。
- **红色足迹**与「我的阅读」共用本地阅读历史（`services/readHistory.js`），首页展示最近 3 篇。
- 资料中心（`pages/resource/list`）：顶部分类筛选栏；资料详情（`pages/resource/detail`）：导语 / 正文 / 关键要点 / 名言，含「收藏」入口。

#### 5.1.2 演出模块（实时互动）
- 演出场次列表：显示时间、主题、状态（即将开始 / 进行中 / 已结束）。
- 演出房间（`packages/show/pages/room`）：游客手机作为投票器与情绪反馈器——**实时投票**（限时投票、结果柱状图/弹幕实时显示）、**表情反馈**（可上大屏）、**短片观看**、**剧情分支**（投票结果决定演员表演分支，系统记录选择路径）。
- 演出回顾（`packages/show/pages/review`）：文字剧情总结与个人选择记录。

#### 5.1.3 创作模块（AIGC 明信片）
- 选择历史场景模板（如"井冈山会师"），自定义名言（系统名言库 + 手动输入，客户端与云函数双敏感词过滤）。
- 排版可定制：**图片方向**（横版 3:2 / 竖版 2:3，匹配图片朝向不旋转）、**名言排列**（横排 / 竖排）、**名言位置**（横排：上/正中/下；竖排：左/中/右）、**字体风格**（大气磅礴 / 铁画银钩 / 雄浑端庄 / 清健瘦劲，对应毛体 / 瘦金 / 颜体 / 柳体，内置字体注入）。
- **AI 生成明信片**：调用文生图 API，结合场景、名言、可选头像生成唯一图片。
- **现场打印**：连接蓝牙/云打印一键打印；无硬件则保存高清图至相册或分享。
- **我的作品**：本地保存创作历史（`services/postcards.js`）；画廊与列表页为两列等宽网格，卡片按真实比例渲染；预览提供「保存 / 分享 / 打印」；长按可删除。落款「红韵智演」+ 日期置于右下角。

#### 5.1.4 我的（个人中心）
- 个人积分与等级（如"新兵"→"宣传员"）、积分记录。
- **积分规则**：阅读一篇文章 +1 积分；参加一次演出 +5 积分；明信片前 5 次生成免费，之后每次生成消耗 1 积分（免费额度按累计生成次数计算，删除作品不回退）。
- **积分商城**（`pages/mall/mall`）：以积分为货币兑换红色文创产品（书签 / 徽章 / 香薰 / 帆布包 / 水杯 / 演出纪念册等），兑换即扣减积分并生成带核销码的订单，可查看「我的兑换」记录；预留微信支付与现场核销。
- **阅读收藏**（`pages/favorites/favorites`，本地收藏，右滑删除/清空）。
- **我的阅读**（`pages/read/read`，本地阅读历史，倒序、标注阅读时间、右滑删除/清空）。
- 工作人员入口（手机号+密码/验证码验证后切换工作人员端视图）。

### 5.2 工作人员端功能

#### 5.2.1 场务角色
- 演出管理：创建/编辑场次、预设投票环节。
- 演出控制台：按序触发开始投票 / 播放短片 / 结束投票；实时修改题目；短片推送；观众情绪监控投屏；现场答题抽奖自动判分。
- 历史演出记录：投票详情、剧情分支回放。

#### 5.2.2 演员角色
- 我的场次与角色。
- **AI 台词助手**：基于当前环节、投票趋势、角色背景实时生成多条备选台词，可滑动选用或自由发挥，支持文字显示与 TTS 语音预览；台词本回看历史场次 AI 台词。

#### 5.2.3 数据看板（轻量）
- 当日游客人数、积分发放量、热门卡片、商城兑换 Top 榜。

## 六、核心业务流程与关键实现

### 6.1 统一服务层
`services/api.js` 封装业务接口，当前以 `setTimeout` 模拟云函数返回；接入真实后端时仅需替换为 `wx.cloud.callFunction`，页面层零改动。云模式遇「云端空集合 / 云函数未部署」自动回退本地 `mock`，保证本地无需灌库即可跑通交互。

### 6.2 演出状态机
严格的环节状态流转（草稿 → 即将开始 → 进行中 → 已结束），所有状态变更由云函数单点串行执行，配合云数据库事务/原子更新防竞态；分支锁定后不可再改。

### 6.3 实时互动（腾讯云 IM 群组）
- 每个场次一个 IM 群组（游客 + 演员 + 场务同群）。
- 下行（场务→游客）：云函数调用 IM REST 推群消息，游客端监听渲染投票器/短片/环节切换。
- 上行（游客→场务）：`pollVote` / `emotionSend` 经云函数写库并广播，结果页轮询/订阅刷新。
- 演员台词：`aiLineGenerate` 调大模型流式输出，经 IM 私信推演员端。
- SLA：指令→游客端 < 1s，投票响应 < 500ms，明信片生成 < 10s。

### 6.4 权限与鉴权
- 游客：微信 openid 身份（`code2Session`）。
- 工作人员：手机号 + 密码/验证码登录；敏感操作需 `staff_verified` 双因子二次验证。
- 云函数统一中间件校验 `role` + `staff_types`，越权返回 `403`；身份以云端 `OPENID` 为准，绝不信任端上传入。

### 6.5 AIGC 双引擎
- **明信片（文生图）**：`postcardGenerate` 组装 Prompt（场景 + 名言 + 可选头像）→ 调文生图 API → 后处理（合成字体/水印/留白）→ 存云存储返回 URL。支持 `customText`（自定义金句，双敏感词过滤）与 `layout`（三种版式，写入记录并还原）。
- **台词（LLM）**：`aiLineGenerate` 结合环节 + 投票趋势 + 角色背景生成多条备选，支持流式与 TTS 预览。

### 6.6 明信片排版引擎（重点自研模块）
`services/pcLayout.js` 为核心自研模块，负责：九宫格定位、名言均衡分行、续行缩进两字符、字号自适应、落款双行右下角、按真实比例（横 3:2 / 竖 2:3）离屏 Canvas 精绘，导出图与预览像素级一致。书法字体经 `services/fonts.js` 由 `wx.loadFontFace` 注入（云存储/HTTPS 二选一，未配置时回退系统字体）。

### 6.7 打印硬件抽象层
统一接口 `printImage(fileID)`，内部适配蓝牙打印机（小程序蓝牙 API）与云打印服务（云存储 + 厂商 API）；无硬件时降级为「保存相册 / 分享」。

### 6.8 设计系统与组件化
- `app.wxss` 统一设计令牌（革命红 `#C8161D` + 暖金 `#E8A33D`、圆角、阴影、安全区），全程 `rpx` 响应式适配；`@media (prefers-reduced-motion: reduce)` 全局关闭动画（无障碍）。
- 复用组件：`re-card`（卡片）、`re-skeleton`（骨架屏）、`re-tag`（标签）、`pc-canvas`（明信片 Canvas 绘制）等。

## 九、软件特色与原创性说明

1. **沉浸式互动演出**：真人演员表演 + 游客实时投票决定剧情走向，结合 IM 实时通道与大屏投送。
2. **AIGC 明信片自研排版引擎**：`pcLayout.js` 实现九宫格定位、均衡分行、缩进、真实比例离屏 Canvas 精绘，预览与导出像素级一致。
3. **双敏感词过滤**：客户端（`sensitive.js`）与云函数双重校验用户输入名言。
4. **轻后端架构**：前端 + 云开发 BFF，密钥不出端，单函数自包含便于部署。
5. **无障碍与适老**：全局字号缩放、`prefers-reduced-motion` 关闭动效。
